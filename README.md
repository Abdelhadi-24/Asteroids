# Asteroids

Asteroids is another [Boot.dev](https://www.boot.dev) project, and is a bit more advanced than BookBot.

It's a simple video game based on the classic [Asteroids](https://en.wikipedia.org/wiki/Asteroids_%28video_game%29). If you've never played before, you can take a look at this [version of the game](https://www.echalk.co.uk/amusements/Games/asteroidsClassic/ateroids.html).
