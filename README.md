# Asteroids

Asteroids is another [Boot.dev](https://www.boot.dev) project, it's a simple video game based on the classic [Asteroids](https://en.wikipedia.org/wiki/Asteroids_%28video_game%29). If you've never played before, you can take a look at this [version of the game](https://www.echalk.co.uk/amusements/Games/asteroidsClassic/ateroids.html).


## Prerequisites

* Python 3.10+
* [uv](https://docs.astral.sh/uv/getting-started/installation/)

## Installation

Clone the repository and install the project dependencies:

```bash
git clone https://github.com/Abdelhadi-24/Asteroids.git
cd Asteroids
uv sync
```

## Running the Game

```bash
uv run main.py
```
